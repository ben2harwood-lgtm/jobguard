# Design choices

## DUI-1a · 23 November 2026

- Capture (v075) uses reference cards and forms for notes, local dictation and the cited draft, drawing on the Quotes companion.
- Scope review (v076) uses reference cards, notices and form controls for source evidence, line decisions, questions and the confirmed state.
- Customer, site and paying party (v077) uses the reference form and description-list patterns for the existing fields and saved details.

## DUI-1b · 23 November 2026

- Pricing (v079) uses reference form cards for existing line controls and a description list for calculated totals and the saved revision.
- Preview (v080) uses the Quotes companion’s document and recipient summary, with the exact PDF, artifact hash and approval action in one card.
- Simulated delivery uses the Quotes companion’s confirmation state and a reference notice to keep the issued, delivered and accepted facts distinct.
