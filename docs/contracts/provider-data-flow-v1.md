# Provider and data-flow register schema v1

Each external route must record: provider and feature; accountable owner; environment; data categories and subjects; purpose and lawful basis; controller/processor roles; origin, processing, storage, log and backup regions; endpoint/deployment identifiers; subprocessors; retention, training and deletion settings; encryption; credentials class; inbound/outbound direction; fallback behavior (default `deny`); D04/D12 evidence references and review date; gate status; kill switch; and verification evidence.

A vendor name or London-facing endpoint is not route approval. Missing fields or an unapproved D04 blocks real-data dispatch.
