## Findings

**P1 — must fix before merge**

1. **0042's new FK is "validated" vacuously when applied by `jobguard_migration` (the Neon/Vercel bootstrap path).**
   `packages/db/migrations/0042_evidence_pack_repair.sql:4-9` rewrites the 0041 policies to `nullif(current_setting('app.tenant_id', true), '')::uuid`; `:18-19` then adds `evidence_pack_revision_exact_case_fk`. Both tables are FORCE RLS and owned by `jobguard_migration`. PostgreSQL's initial FK check runs as the current user with RLS applied when the owner is subject to FORCE RLS, and with no tenant context the policy now admits zero rows, so the check passes without looking at any data and `pg_constraint.convalidated` is set to true. The policy change cured the 42704 crash the 8116aa6 verdict found, but replaced it with a silent non-check. `packages/db/MIGRATIONS.md:116` ("before foreign-key validation by `jobguard_migration`") overstates what happens.
   Evidence (my test R101-A, below): on a 0041 database holding one revision whose `case_id` differs from its pack's `case_id` (legal under 0041's FKs), applying 0042 under `SET ROLE jobguard_migration` → **applied**, `convalidated = true`, **1 violating row**. Control: the same 0042 applied as superuser → **rejected 23503**.
   **Exact fix (tested, R101-A-FIXED):** in 0042, immediately before line 18 add
   `ALTER TABLE app.evidence_pack NO FORCE ROW LEVEL SECURITY; ALTER TABLE app.evidence_pack_revision NO FORCE ROW LEVEL SECURITY;`
   and immediately after the FK statement (before line 20) add
   `ALTER TABLE app.evidence_pack FORCE ROW LEVEL SECURITY; ALTER TABLE app.evidence_pack_revision FORCE ROW LEVEL SECURITY;`
   (same transaction, so FORCE is never off outside the migration). With that patch, under `SET ROLE jobguard_migration`: the inconsistent row → rejected 23503; consistent data → applies, FORCE restored on both tables, `convalidated = true`. Add a DB test that seeds an inconsistent 0041 row and asserts the role-based apply rejects it, and one that consistent rows apply; correct the MIGRATIONS.md sentence. Keep the policy rewrite (it is still needed so the policies stop raising 42704).
