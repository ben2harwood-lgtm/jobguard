# DUI-4 invoice through paid report

Chromium captures from persisted fictional jobs at 360 × 800 and 1280 × 800. Money uses the saved invoice, receipt and value projections. Records links to the saved payment evidence in Money. All amounts shown follow the existing display formats.

The clickable reference has a Money empty state and generic specimens v101 (final invoice), v102 (invoice and payment record), v103 (value and fee) and v105 (credits and reversals). It has no finished paid report. The table records how the reference kit was applied to the working states.
