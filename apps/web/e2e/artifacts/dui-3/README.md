# DUI-3 Final Check visual evidence

Chromium at 360 × 800 and 1280 × 800. The working screenshots use a fictional own job. Results and the confirmed catch come from the saved Final Check, and the processing capture uses a separate job with an unreadable pre-lock source.

The standalone clickable preview was unavailable. The comparison uses the same [16 October interface candidate](https://github.com/ben2harwood-lgtm/jobguard/tree/7b909f72b48558facaf483755ea282e592a800e0) as DUI-2. The final-account companion is interactive. Views v097–v100 are catalogue specimens.
